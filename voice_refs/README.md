# Голоса девочек

Образцы `anya.wav`, `alisa.wav`, `tanya.wav` созданы моделью Qwen3-TTS-12Hz-1.7B-VoiceDesign (Apache 2.0)
по текстовому описанию 24.11.2026. Это синтетические голоса: ни один человек их не записывал,
поэтому чужих прав на них нет. `voice_qwen.py` говорит ими через Qwen3-TTS-12Hz-0.6B-Base.

Описание: "A young woman around twenty, warm, soft and lively voice, speaks like a close friend,
gently smiling, natural intonation, not too high-pitched." Каждый запуск дал свой вариант голоса.
Текст, который читается в образце, — `REF_TEXT` в `voice_qwen.py`.

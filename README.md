# ИИ-компаньон «Подруга» — простая версия для Mac

Живая подруга на экране: просыпается по «привет, подруга», разговаривает голосом,
помнит тебя между днями, засыпает по «спокойной ночи», уходит на паузу во время игр.
Видеокарта не нужна: «мозг» и голос — в облаке Gemini, остальное — на Mac.

## Установка (один раз, ~5 минут)
1. **Ключ Gemini (бесплатно):** зайди на https://aistudio.google.com/apikey → войди в Google →
   **Create API key**. Нажми на созданный ключ → в строке **API Key** значок копирования справа.
   Ключ начинается на `AQ.` (или `AIza` у старых ключей).
2. **Распакуй архив** (например, на Рабочий стол).
3. Двойной клик по **`setup_mac.command`**.
   Если Mac пишет «неизвестный разработчик»: правый клик → «Открыть» → «Открыть».
   Если Python нет — откроется python.org: скачай «macOS installer», установи, запусти снова.
   Установщик сам поставит всё нужное и скачает голоса. В конце вставь ключ (**Cmd+V**, Enter).
   Должно появиться «Ключ сохранён» и список моделей.

## Запуск
- **`start_text_mac.command`** — проверка перепиской, без микрофона.
- **`start_mac.command`** — полный режим. Лучше в наушниках.
  Mac спросит доступ к микрофону для Терминала → **Разрешить**.

## Как с ней говорить
- После запуска она **спит** (на экране окошко с ней, глаза закрыты).
- **«Привет, подруга»** — просыпается и здоровается. Можно сразу с вопросом:
  «Привет, подруга, как дела?»
- Дальше просто говори. После фразы сделай паузу ~1 секунду — так она понимает, что ты закончил.
- **«Спокойной ночи»** (или «пока, подруга») — прощается, засыпает и больше не слушает.
- Окно с ней можно перетащить мышкой.

## Настроить под себя (`config.yaml`, открывается в TextEdit)
- `user_name` — как она тебя называет. `companion_name` — её имя.
- `gemini_voice` — голос. Послушать 8 вариантов: **`voice_samples_mac.command`**.
- `style` — манера речи («милый, тёплый, игриво» и т.п.).
- `wake` → фразы, которые будят и усыпляют.
- `autopause` → `games` — игры, во время которых она молчит.
- `character.md` — характер. Главный файл: от него зависит, какая она.

## Если что-то не так
- «API key not valid» → неверно скопирован ключ. Переименуй файл `.env` (он скрытый: Cmd+Shift+. в
  Finder показывает скрытые файлы) и запусти `setup_mac.command` снова.
- Не слышит → в `config.yaml` уменьши `energy_threshold` (подобрать: `mic_test_mac.command`).
- Слышит всё подряд → увеличь `energy_threshold`.
- Отвечает сама себе → наушники.
- Не реагирует на «привет, подруга» → говори чётче, или запусти `update_mac.command`
  (докачает распознаватель фраз).

## Сколько стоит
На бесплатном уровне Gemini — 0 ₩ в пределах дневных лимитов (Google может использовать
тексты для улучшения своих моделей). На платном — примерно $0.2–0.4 за час разговора
(мозг + голос), с 2027 голос дорожает вдвое.

Своё (память, журнал, ключ) хранится только у тебя: `data/` и `.env`.

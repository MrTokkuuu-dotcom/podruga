# Свой мозг (v29) — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Аня думает своей моделью Gemma 4 E4B на Mac, без Google; Google — только по выбору в настройках.

**Architecture:** `local_brain.LocalBrain` повторяет набор методов `GeminiBrain`, поэтому `main.py`, `memory.py`,
`initiative.py` почти не меняются. Модель (mlx-lm) в одном потоке, кэш «характер+правила+память» считается один раз,
история дописывается к кэшу. Простые команды (музыка, громкость, таймер) — `intents.py`, без мозга. Поиск — DuckDuckGo.

**Tech Stack:** Python 3.11, mlx 0.32.4, mlx-lm 0.32.2 (+ transformers, ставит uv), ddgs, mlx-vlm 0.8.0 (только экран).

**Spec:** `docs/superpowers/specs/2026-11-23-svoy-mozg-design.md`

## Global Constraints
- Модель: `lmstudio-community/gemma-4-E4B-it-MLX-4bit` → `~/Podruga/models/brain/gemma-4-E4B-it-MLX-4bit/`.
- Пакеты ставятся фоном через `~/Podruga/bin/uv` в venv приложения, как `stt.MlxWhisperSTT._install`; неудача → файл-метка `.local_brain_failed`, больше не пытается. В подписанном (`PODRUGA_BUNDLED`) — не ставить.
- Первая фраза ≤ ~1 с после конца распознавания; журнал `[мозг] свой: первая фраза N с, M ток/с`.
- Без перезапусков, пока Дима говорит (смотреть `log.txt`). Ключи/`.env`/`data/` не коммитить.
- Нет pytest — проверки: скрипты `devtools/test_*.py` с `assert`, запуск `~/Podruga/venv/bin/python devtools/test_X.py`, печатают `OK`.

## Review Focus
- Модель ещё качается / не встала → Аня отвечает (Google при ключе, иначе заготовки + честная фраза), не молчит и не падает.
- Он заговорил, пока модель отвечает на `say_once` (продолжение/инициатива) → запросы по очереди, без падения MLX и без перемешанных ответов.
- Длинный разговор: история вытесняет старые реплики → кэш пересобирается, ответ по-прежнему быстрый (< 2 с).
- Сменили девочку/ползунки/память обновилась → новая подсказка, старый характер не «залипает».
- Нет интернета → разговор работает, поиск честно говорит «нет интернета».

### Task 2: Мозг на Mac — `local_brain.py`
**Files:** Create `local_brain.py`, `devtools/brain_check.py`. Modify `stt.py` нет (только образец).

**Interfaces:**
- Consumes: Task 1.
- Produces: `class LocalBrain(home: Path, notify: Callable[[str], None])` с
  `ready: threading.Event`, `failed: bool`,
  `set_system(stable: str) -> None` (пересчёт кэша в фоне, если текст изменился),
  `stream_reply(system, history, wav=None, text=None, image=None, image_mime=...) -> Iterator[str]` (system — свежая часть; `wav` не поддерживается → `ValueError`),
  `say_once(system: str, instruction: str) -> str`, `chat(messages, options=None) -> str`,
  `search(query, context="") -> str` (Task 4), `unload() -> bool`, `preload() -> bool`.
- Один `threading.Lock` на все вызовы модели. `max_tokens` 200 для ответа, 120 для `say_once`, 400 для `chat`; temp 0.8 / chat 0.2.
- Кэш: `make_prompt_cache` после стабильного префикса (как `bench.py` в замере: префикс шаблона до первого user-сообщения, `deepcopy` на каждый ответ). История+фраза — каждый раз от кэша префикса (просто и надёжно; замерить, если история длинная > 1 с — тогда дописывать к кэшу).
- Чат-шаблон через `apply_chat_template(..., enable_thinking=False)` с откатом без параметра.

- [ ] `devtools/brain_check.py`: 16 фраз (13 из замера + «громче», «поставь таймер на 5 минут», «Сань, я сам сделаю») через `LocalBrain`, проверки: нет мужского рода у неё (`я понял|рад |устал |сам |готов ` в ответе → ошибка), команды для ютуба/поиска/таймера/напоминания разобраны `ReplyParser`, ответ en/ko на своём алфавите, «не мне» → `parser.skip`. Печатает счёт `N/16` и медиану первой фразы.

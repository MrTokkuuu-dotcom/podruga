# Чужие модели, данные и библиотеки — можно ли продавать

Правило Димы (24.11.2026): в Подругу ставим только то, что можно сразу использовать в платном приложении.
Проверено 24.11.2026: лицензии библиотек — по их установленным метаданным, данные и модели — по официальным страницам.

## Нельзя продавать — заменить до продажи (было и до v29)
| Что | Где | Лицензия | Что делать |
|---|---|---|---|
| Голос Silero (Ксения), `silero_v5_6_ru.pt` | с 24.11 только запасной, пока живой голос качается (`voice_silero.py`) | CC BY-NC (некоммерческая) | убрать из продаваемой сборки |
| piper-tts 1.8.0 + голоса Piper (Irina, Amy) | английский голос и запасной (`tts.py`) | библиотека GPL-3.0; русские голоса Piper некоммерческие по происхождению | заменить (например, системные голоса macOS) |

## Можно, но с условиями
| Что | Условие |
|---|---|
| pynput (горячая клавиша паузы) | LGPL-3.0: можно в платном приложении, если пользователь может заменить библиотеку; в подписанном приложении проще заменить на pyobjc |
| av (PyAV, нужен faster-whisper — запасной слух) | сам BSD, внутри FFmpeg под LGPL — те же условия; если запасной слух убрать, уйдёт и он |
| Модели девочек из VRoid Studio | условия VRoid для готовых деталей (preset) — **не сверено**, сверить перед продажей |
| Ключ Google (Gemini) | по условиям Google для того, чей ключ; для продажи — платный тариф |

## Убрано, потому что продавать нельзя
- Open-Meteo (погода) — бесплатно только некоммерчески → заменено на MET Norway.
- ddgs (поиск через Яндекс/Google/Bing) — обходит условия поисковиков → убран. Курс, новости, цены — только через ключ Google.
- Курс ЕЦБ — разрешение на коммерческое использование прямо не написано → не используем.
